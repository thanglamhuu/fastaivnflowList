ADMIN LICENSE UPDATE – STEP 3
UPDATE CREATE LICENSE FLOW

Mục tiêu:
Admin cấp License cho Flow App bằng Signed License Token.

Không tạo Device License document cho Flow App đọc nữa.

Không còn cần:

machines/{machineId}/projects/{projectId}/licenses/{licenseKey}

cho Flow App.

Flow App không truy cập Firebase.

==================================================
1. BUTTON
==================================================

Giữ button:

+ Cấp License

==================================================
2. CREATE LICENSE MODAL
==================================================

Form gồm:

EMAIL KHÁCH HÀNG

Ví dụ:
customer@gmail.com


PROJECT / FLOW APP

Dropdown lấy từ Projects hiện có.

Hiển thị:

Project Name
Project ID


MACHINE ID

Input text.

Placeholder:

Dán Machine ID khách gửi từ Flow App

Ví dụ:

88b9c812-xxxx-xxxx-xxxx-xxxxxxxxxxxx


THỜI HẠN

1 tháng
3 tháng
6 tháng
12 tháng

Có thể nhập custom nếu hệ thống hiện tại hỗ trợ.


NGÀY BẮT ĐẦU

Mặc định:

Ngay khi phát hành Token

Do Flow App xác minh offline,
không sử dụng "bắt đầu khi user activate" nữa.

issuedAt = thời điểm Admin tạo token.


GHI CHÚ

Textarea.

==================================================
3. VALIDATION
==================================================

Không cho tạo Token nếu thiếu:

customerEmail
projectId
machineId
duration

Normalize:

email trim lowercase

machineId trim

Project ID lấy từ Project object,
không cho Admin nhập tay nếu đã chọn Project.

==================================================
4. CALCULATE EXPIRY
==================================================

Khi Admin submit:

issuedAt = current time

expiresAt = issuedAt + duration

Sử dụng cùng utility tính thời gian trong toàn hệ thống.

Không lấy expiresAt từ input user nếu không có chức năng custom date.

==================================================
5. CREATE MASTER LICENSE RECORD
==================================================

Lưu Firestore:

projects/{projectId}/licenses/{licenseId}

Document gồm:

licenseId
projectId
customerEmail
licensedEmailMasked
machineId

durationMonths
planLabel

status:
ACTIVE

issuedAt
expiresAt

keyId

tokenVersion:
1

createdBy
createdAt
note

Không bắt buộc lưu full License Token trong Firestore.

Ưu tiên KHÔNG lưu full token nếu không cần.

Có thể lưu:

tokenIssued: true

==================================================
6. GENERATE TOKEN
==================================================

Sau khi Master License Record hợp lệ:

gọi:

generateSignedLicenseToken()

Payload phải sử dụng dữ liệu vừa tạo.
