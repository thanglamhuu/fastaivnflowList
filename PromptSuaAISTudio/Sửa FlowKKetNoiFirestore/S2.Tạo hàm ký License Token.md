ADMIN LICENSE UPDATE – STEP 2
CREATE SIGNED LICENSE TOKEN SERVICE

Chỉ thực hiện logic ký License Token.

Không sửa nhiều UI trong step này.

==================================================
1. TOKEN FORMAT
==================================================

Flow App đang sử dụng format:

base64url(payload) + "." + base64url(signature)

Admin phải tạo CHÍNH XÁC format này.

Không dùng JWT library nếu Flow App không dùng JWT.

Không thêm header JWT.

Token chỉ gồm:

PAYLOAD.SIGNATURE

==================================================
2. PAYLOAD
==================================================

Payload version 1 gồm:

version
keyId
licenseId
projectId
machineId
licensedEmailMasked
planLabel
issuedAt
expiresAt

Ví dụ:

{
  "version": 1,
  "keyId": "af-license-2026-01",
  "licenseId": "LIC-001",
  "projectId": "DyoEwgDvZ2xDNL34nZ7m",
  "machineId": "UUID-MACHINE",
  "licensedEmailMasked": "a***@gmail.com",
  "planLabel": "3 tháng",
  "issuedAt": 1789488000,
  "expiresAt": 1797350400
}

issuedAt và expiresAt dùng Unix timestamp theo giây.

==================================================
3. SERIALIZATION
==================================================

Serialize payload một lần:

JSON.stringify(payload)

Encode UTF-8 bằng TextEncoder.

Sau đó base64url encode.

QUAN TRỌNG:

Signature phải được tạo trên CHÍNH bytes mà Flow App verify.

Không stringify payload lại sau khi ký.

Không thay đổi field order sau khi tạo payloadPart.

==================================================
4. SIGNATURE
==================================================

Đọc:

privateJwk

từ:

system/licenseSigningKeys/current

Import bằng:

crypto.subtle.importKey()

Algorithm:

ECDSA
namedCurve: P-256

Sign:

crypto.subtle.sign(
  {
    name: "ECDSA",
    hash: "SHA-256"
  },
  privateKey,
  bytesToSign
)

bytesToSign phải đúng với implementation hiện tại của Flow App.

Nếu Flow App verify:

payloadPart encoded text

thì Admin phải sign đúng payloadPart encoded text.

Nếu Flow App verify decoded payload bytes:

Admin phải sign decoded payload bytes.

Hãy kiểm tra implementation Flow App hiện tại và làm giống CHÍNH XÁC.

Không tự chọn format khác.

==================================================
5. BASE64URL
==================================================

Tạo helper chuẩn cho:

ArrayBuffer -> base64url

UTF8 JSON -> base64url

Base64url:

+ đổi thành -
/ đổi thành _
bỏ dấu = cuối chuỗi

==================================================
6. OUTPUT
==================================================

Function:

generateSignedLicenseToken(...)

trả về:

{
  token,
  payload
}

Không lưu Private Key trong output.

Không log token nếu không cần thiết.
