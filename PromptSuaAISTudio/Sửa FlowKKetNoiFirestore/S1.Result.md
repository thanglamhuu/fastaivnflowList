Đã hoàn thành STEP 1: CREATE SIGNING KEY MANAGEMENT cho hệ thống License theo đúng các tiêu chuẩn kỹ thuật và nguyên tắc bảo mật.
Báo cáo chi tiết theo yêu cầu:
Signing Key document path:
licenseSigningKeys/current
(Chuẩn hóa từ system/licenseSigningKeys/current để tuân thủ quy tắc số phân đoạn chẵn bắt buộc của Firestore Document Reference: collection('licenseSigningKeys') / doc('current'). Đồng thời firestore.rules cũng hỗ trợ dự phòng cả path phân cấp system/licenseSigningKeys/keys/{keyId}).
Algorithm:
ECDSA
Named Curve: P-256
Hash: SHA-256
Thực thi tạo khóa bằng Web Crypto API tiêu chuẩn (crypto.subtle.generateKey), hoàn toàn không sử dụng Math.random().
keyId:
Tạo định dạng chuẩn: af-license-YYYY-MM-XXXX (ví dụ: af-license-2026-09-xxxx) thông qua window.crypto.getRandomValues() an toàn bảo mật.
Public Key lấy ở đâu:
Lấy trực tiếp từ Firestore document tại trường publicJwk.
Trên giao diện quản trị Admin Web (/admin/licenses?tab=signing-key hoặc tab Khóa Ký License (Signing Key)), Public Key được hiển thị dưới dạng JSON đầy đủ kèm nút Copy Public Key để nhúng vào Flow App xác minh License Token offline.
Private Key lấy ở đâu:
Được lưu trữ bảo mật duy nhất trong Firestore document tại trường privateJwk.
Chỉ được tải trực tiếp từ Firestore trong phiên làm việc của tài khoản có vai trò afrole == 'afadmin' khi cần thực hiện ký License Token.
Tuyệt đối không hiển thị trên UI, không có nút copy, không xuất hiện trong logs, không nhúng vào Flow App.
File đã tạo:
/src/services/signingKeyService.ts: Khởi tạo và truy vấn cặp khóa ECDSA P-256 bằng Web Crypto API, đọc/ghi Firestore document an toàn.
/src/components/admin/LicenseSigningKeyManager.tsx: Giao diện quản lý Signing Key (kiểm tra tồn tại, tạo khóa lần đầu, hiển thị metadata & Public Key JWK).
File đã sửa:
/src/types.ts: Bổ sung interface LicenseSigningKeyDocument.
/src/pages/AdminLicensesPage.tsx: Tích hợp 2 tab chuyển đổi (Danh sách License & Khóa Ký License (Signing Key)).
/src/components/Header.tsx: Bổ sung liên kết nhanh đến Khóa Ký License (Key) trong menu tài khoản Admin.
/firestore.rules: Bổ sung quy tắc bảo mật chỉ cho phép Admin (afrole == 'afadmin') đọc/ghi licenseSigningKeys/{keyId}, chặn hoàn toàn Anonymous và người dùng thường (đã triển khai bằng deploy_firebase).
/firebase-blueprint.json: Khai báo thực thể LicenseSigningKey và mapping collection licenseSigningKeys.
