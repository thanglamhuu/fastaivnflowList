ADMIN LICENSE UPDATE – STEP 5
REISSUE TOKEN FOR RENEWAL AND DEVICE CHANGE

QUAN TRỌNG:

Flow App không kết nối Firebase.

Vì vậy chỉ UPDATE Firestore expiresAt
KHÔNG làm Token trong Flow App thay đổi.

Mọi thay đổi liên quan đến:

expiresAt
machineId

phải phát hành SIGNED TOKEN MỚI.

==================================================
1. RENEW LICENSE
==================================================

Khi Admin chọn:

Gia hạn

Mở modal:

License hiện tại
Current expiresAt

Chọn:

+1 tháng
+3 tháng
+6 tháng
+12 tháng

Logic:

Nếu current expiresAt > now:

newExpiresAt =
current expiresAt + selected duration

Nếu đã hết hạn:

newIssuedAt = now
newExpiresAt =
now + selected duration

Giữ nguyên:

licenseId
projectId
machineId
customerEmail

Update Master License Record.

Sau đó generate Signed License Token MỚI.

Success modal:

GIA HẠN THÀNH CÔNG

Token mới:
[...]

COPY TOKEN MỚI

Warning:

"Khách hàng cần thay License Token cũ trong Flow App bằng Token mới."

==================================================
2. CHANGE DEVICE
==================================================

Action:

Đổi thiết bị

Modal hiển thị:

Machine ID hiện tại
Machine ID mới

Admin nhập Machine ID mới.

Update Master License:

machineId = newMachineId

issuedAt = now

expiresAt:
GIỮ nguyên expiry hiện tại,
trừ khi Admin đồng thời chọn gia hạn.

Generate Token mới.

Success:

THIẾT BỊ ĐÃ ĐƯỢC THAY ĐỔI

License Token mới:
[...]

Warning:

"Token cũ vẫn có thể hoạt động trên thiết bị cũ đến expiresAt vì Flow App xác minh offline."

==================================================
3. REVOKE
==================================================

Action:

Thu hồi trên hệ thống

Set:

status = REVOKED

Không xóa record.

Hiển thị warning xác nhận:

"Flow App không kết nối Firebase. Thu hồi này không thể vô hiệu hóa ngay Token đã phát hành. Token hiện tại vẫn có thể hoạt động đến ngày hết hạn."

Không tạo Token mới sau khi status REVOKED.

Nếu muốn cấp lại:
Admin phải chuyển trạng thái qua flow riêng hoặc tạo License mới.
