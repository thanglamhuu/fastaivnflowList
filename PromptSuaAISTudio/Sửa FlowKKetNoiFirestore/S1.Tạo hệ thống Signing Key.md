ADMIN LICENSE UPDATE – STEP 1
CREATE SIGNING KEY MANAGEMENT

QUAN TRỌNG:

Flow App đã được chuyển sang cơ chế Signed License Token.

Flow App:
- KHÔNG kết nối Firebase
- KHÔNG sử dụng Firestore
- KHÔNG có Private Key
- chỉ có Public Key
- verify License Token offline bằng Web Crypto API

Admin Web vẫn sử dụng:
Firebase Authentication
Firestore

Admin hợp lệ khi:

users/{uid}.afrole == "afadmin"

Không tạo backend.
Không tạo Cloud Functions.
Không tạo Node server.

Chỉ thực hiện STEP 1.

==================================================
1. MỤC TIÊU
==================================================

Tạo một Signing Key Pair duy nhất dùng cho hệ thống License.

Algorithm phải giống Flow App:

ECDSA
P-256
SHA-256

Sử dụng Web Crypto API:

crypto.subtle.generateKey()

Không sử dụng Math.random().

==================================================
2. FIRESTORE PATH
==================================================

Lưu Signing Key tại private document:

system/licenseSigningKeys/current

Hoặc nếu cấu trúc Firestore hiện tại yêu cầu path khác,
có thể điều chỉnh nhưng phải giữ cùng ý nghĩa.

Document gồm:

keyId
algorithm
curve
publicJwk
privateJwk
createdAt
createdBy
status

Ví dụ:

keyId:
af-license-2026-01

algorithm:
ECDSA

curve:
P-256

status:
ACTIVE

==================================================
3. SECURITY
==================================================

Document chứa Private Key chỉ AF Admin được:

GET
CREATE
UPDATE

Anonymous:
DENIED

User không phải afadmin:
DENIED

Không đưa privateJwk vào:

Project documents
License documents
localStorage
public config
VITE environment variables
console.log
frontend source code

Private Key được đọc từ Firestore chỉ trong phiên Admin cần ký License.

Không lưu Private Key lâu dài trong localStorage.

==================================================
4. INITIALIZATION
==================================================

Khi Admin mở phần License Signing:

Kiểm tra document:

system/licenseSigningKeys/current

Nếu đã tồn tại:
reuse key pair hiện tại.

TUYỆT ĐỐI không tự generate key mới mỗi lần mở trang.

Nếu chưa tồn tại:

hiển thị:

"Chưa có License Signing Key"

Button:

Khởi tạo Signing Key

Chỉ khi Admin bấm mới generate.

Sau khi generate:

export Public Key thành JWK.

export Private Key thành JWK.

Lưu document private lên Firestore.

==================================================
5. PUBLIC KEY DISPLAY
==================================================

Admin cần xem được Public Key để đưa vào Flow App.

Tạo section:

LICENSE PUBLIC KEY

Hiển thị publicJwk dạng JSON.

Có button:

Copy Public Key

Có hướng dẫn nhỏ:

"Public Key này được nhúng vào Flow App để xác minh License Token. Public Key có thể công khai; không được đưa Private Key vào Flow App."

==================================================
6. PRIVATE KEY
==================================================

Không hiển thị Private Key trên UI mặc định.

Không có button Copy Private Key.

Không console.log privateJwk.

==================================================
7. KEY ROTATION
==================================================

Chưa làm chức năng Rotate Key ở step này.

Chỉ hiển thị:

Key ID
Created At
Created By
Status

Không tự regenerate key.

==================================================
8. SAU KHI HOÀN THÀNH
==================================================

Báo:

1. Signing Key document path
2. Algorithm
3. keyId
4. Public Key lấy ở đâu
5. Private Key lấy ở đâu
6. File đã tạo
7. File đã sửa
8. Xác nhận không lưu Private Key vào localStorage
